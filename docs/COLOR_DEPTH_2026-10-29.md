# Engineering colour refinement

The portfolio keeps its midnight-blue foundation and four project inks:
blue for ATLAS, violet for analytics, teal for pathfinding and amber for
security. Names, numbers and written labels remain the primary identifiers.

The animated system figure now has a dedicated navy palette in either page
theme, with blue plate faces, coloured layer edges and high-contrast labels
and controls. The contact block uses a dark navy-to-royal-blue gradient and
an ice-blue primary action. These two feature panels provide the strongest
colour areas while project prose stays on calm reading surfaces.

Project links, preview headers, project titles, role cards, summary numerals,
education panels and method cards repeat the same four accents. Background
washes, borders and restrained shadows give the panels more separation.
The reading scale, pause/replay behavior and motion preferences are retained.

## Verification

- Offline site integrity, JavaScript syntax and unit checks.
- The existing browser suite covers desktop and phone layouts in both themes,
  reader text spacing, zoom availability, inputs, controls and the real labs.
- Dedicated contrast checks cover the feature panel inks, contact gradient
  stops, contact action and all four tinted project headers. Body/secondary/
  fine reading inks retain their existing 7:1 tests on plain reading surfaces.
- Cloud-browser visual review covers both themes and narrow phone layouts.

No dependencies, remote fonts, new runtime requests or data feeds are added.
The change is CSS presentation and content-versioned stylesheet links;
project descriptions and the research publication boundaries are unchanged.
