# System layer zoom — 29 October 2026

Selecting a hero layer now zooms the actual isometric SVG surface into focus instead of only highlighting its outline. The camera fits the complete selected slab to a 500-unit width inside the 600 × 560 drawing. It measures the generated slab geometry, centres that surface, restores the original painter order and draws the selected plate last. The surrounding stack remains faintly visible for spatial context. Drafting labels and connecting signals are hidden while focused, so they do not cross the enlarged surface.

Visitors can click or tap a visible plate or choose one of the five native controls above the drawing. Selecting the same layer again returns to the overview; Full system and Escape also reset the view. A new plain-language description and three component labels explain each layer, alongside its existing related-work link. No project claims, result figures or publication gates change. This remains a conceptual system model, not an operational dashboard.

## Desktop, mobile and keyboard

- The camera uses SVG and a CSS transform, so geometry remains sharp without a raster image, WebGL engine or added runtime dependency.
- The layer controls are above the viewport and keep the existing responsive grid and minimum 44px touch targets. After a selection, the page moves only as much as needed to bring the controls and focused surface into view below the fixed header.
- The enhanced SVG exposes its five plates as buttons, with a single roving tab stop, pressed states and a visible focus outline. Enter or Space selects or resets; arrows switch layers, Home and End select the first and last layers. Painter-order changes preserve keyboard focus.
- Ambient floating stops while a layer is focused, so the surface stays centred and stable. The remembered pause preference, offscreen suspension and hidden-tab suspension still govern the overview animation.
- Reduced motion preserves inspection with instant camera changes and no automatic motion, including preference changes made without reloading.
- Without JavaScript, the controls and inspector stay hidden. The SVG keeps its image role and the complete five-layer legend remains available.

## Validation

`npm test` covers the static site checks, shared JavaScript syntax, generated SVG consistency and all existing unit tests. The camera and plate wrapper are generated by `scripts/hero-section.js`; `index.html` contains exactly that generated drawing.

Six browser checks exercise every layer on desktop, 375px touch and 320px touch viewports; direct clicks on every exposed plate face; repeated and rapid switching; complete and centred camera framing; restoring painter order; keyboard focus and Escape; and reduced-motion preference changes. Existing tests continue to cover readable typography, no-JavaScript fallback, pause persistence, offscreen motion, project previews and all three labs. Browser checks run in the repository's GitHub Actions Chromium environment; the local executor does not have its browser executable installed. Desktop and phone layouts are also reviewed in the managed browser preview.

The strict content security policy and dependency-free delivery are preserved. Shared asset URLs are refreshed from their content hashes.
