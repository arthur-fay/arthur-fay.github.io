A closer look at ATLAS

Research with the uncertainty left in.

Good engineering isn't only about what a system can do. It's also about what its evidence can actually support.

01 — QUESTION

Can historical demand be modeled responsibly?

ATLAS investigates historical NYC 311 request counts through a reproducible backtesting pipeline and documented model comparisons.

02 — ENGINEERING

Build the system around reproducibility.

Versioned inputs, integrity checks, Python analysis, a FastAPI interface, a React dashboard, browser tests, and prepared deployment profiles.

03 — SCIENTIFIC RESULT

Disclose what did not validate.

The claimed forecasting improvement is not conclusively established, and the prediction intervals failed calibration. The system preserves these findings.

04 — BOUNDARIES

Separate scenarios from decisions.

The optimization component demonstrates mathematical techniques with hypothetical parameters; it does not make verified NYC resource recommendations.

NYC Open Data is independently attributed in the source project. No NYC-derived charts or datasets are hosted on this portfolio.
